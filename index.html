Cómo usar la captura por voz

Toca el botón 🎤 y dicta el pedido. Ejemplos:

  • "modelorama berlín" — elige el cliente
  • "tres mango cuarto, dos tamarindo medio" — agrega productos (cantidad + producto)
  • "cinco ajonjoli" — agrega 5 ajonjolí
  • "quita mango cuarto" — elimina ese producto
  • "limpia carrito" — vacía el carrito
  • "imprime ticket" — abre el ticket para imprimir
  • "guarda venta" — guarda la venta

Puedes dictar todo de una sola vez: "modelorama berlín tres mango cuarto dos ajonjoli imprime ticket"
